# zh-TW 語言層——繁體中文文件加驗這層

適用:文件本體為繁體中文時。本層違規是 owner review 被打回率最高的一類。

## 全形標點

- 中文句內一律全形:,。:;()?!。
- 保持半形的例外:code 與 port(`NLB:80`)、CVSS 向量(`PR:L`)、URL、數字千分位、(a)(b) 列舉。

### 輸出層陷阱(agent 寫中文必讀)

- 部分 agent 輸出層會把全形 ASCII-variant 標點折成半形。寫轉換腳本必須用
  `chr(0xFF0C)` 等 code point 生成字元,絕不用字面值;每個 `str.replace`
  執行後都要 grep 驗證落地——replace 對不上是**靜默 no-op**。
- 處理 HTML/storage 文字節點時,`&sect;` `&rarr;` 等 entity 的結尾分號也是
  `;`——無條件的 `;`→`;` 轉換會打斷 entity,渲染出「§;」類垃圾。規則:`;`
  只在前一字元是 CJK/全形時才轉;或先用 `&[a-z]+;` 遮罩 entity 再轉。
- 轉換器固定一份、重複使用;每次手寫變體必然 drift。

## 用語

### 大陸用語 → 台灣用語

信息→資訊、默認→預設、調用→呼叫、代碼→程式碼、緩存→快取、內存→記憶體、
字段→欄位、支持→支援、服務器→伺服器、網絡→網路、集群→叢集(或 cluster)、
灰度→加權導流/canary、反饋→回饋、視頻→影片、靜默→無預警/不報錯(silent
failure 語境)。「數據」在「實測數據」語境可接受。

### 非台灣慣用譯名 → 直接用英文原文

baseline(勿:基線)、rollback(勿:回滾/回退)、dump(勿:傾印)、
code block(勿:指令塊/參數塊)。

### 自造壓縮詞禁令

判準:**壓縮詞若需要讀者反解,就寫全。**

| 勿寫 | 改寫 |
|---|---|
| 「窗」字家族(硬窗/排窗/切換窗/干擾窗) | 「不可提前也不可事後補算」「切換時段」等白話 |
| 放行 | 判定標準/門檻 |
| 佈建 | 建立 |
| 掉錯 index | 「log 會被送錯索引,查 log 的人找不到」 |

- 自造行話(「認領」「對帳」之類的借喻)首次出現必須就地解釋,或直接改白話。
- 裸 port 號、裸代號不進讀者面警語(「過不了 :10254 健檢」→「nginx 專屬的
  健康檢查端點」);接線規格、參數定義才保留精確值。
